# Fish in Space [Fishing Simulator]

Scripts exported from the Roblox place (placeId 120283953214063) on 2026-11-16.

`src/` mirrors the game's Explorer tree:

- `*.server.luau`: Script (server)
- `*.client.luau`: LocalScript, or a Script with RunContext = Client
- `*.luau`: ModuleScript
- `init.*.luau`: a script that has child scripts (the folder holds those children)

Duplicate names in the same parent get a `_2`, `_3` suffix.
`ServerStorage/*Backup*` and `ServerStorage/OldShipLobby` are old versions kept in the place.

This is a snapshot. Roblox Studio is still where the game lives. Re-export after big changes.
